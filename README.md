# novteko-site

Site institucional da Novteko Sistemas Ltda (CNPJ 69.811.486/0001-44).
HTML estático, sem build: `index.html` e os ícones dos produtos.

Endereço: https://www.novteko.com (o arquivo `CNAME` é do GitHub Pages). DNS e Email Routing na Cloudflare.

Para ver localmente: `python3 -m http.server` e abrir http://localhost:8000.
